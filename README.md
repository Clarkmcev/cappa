## Introduction

This is a simple static website built to showcase my paintings. The website is built using modern web technologies and is designed to be fast, responsive, and easy to navigate.

## Features

- Display a gallery of paintings
- Responsive design for mobile and desktop
- Easy navigation through different sections
- Hosted using Docker and Caddy for simplicity and performance

## Setup

Docker image and caddy container running statically frontend code.
